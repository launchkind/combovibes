=====================================
KEY NOTES
=====================================

  - Cashfree webhook  →  triggers payment confirmation + Shiprocket creation
  - Shiprocket webhook →  triggers status updates (shipped / delivered etc.)
  - If Shiprocket fails after payment, admin can retry manually from /admin/orders/[id]
  - Cart is cleared ONLY after payment_status = "paid" (never on order creation)
  - Prices are always re-fetched from DB — client-sent prices are ignored
  - Guest orders have user_id = NULL; accessible via order UUID only
